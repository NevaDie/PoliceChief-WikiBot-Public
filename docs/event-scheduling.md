# Event Scheduling

WikiBot supports one-time and recurring alliance schedules using Discord timestamps, configured time zones, and automatic daylight-saving handling.

Start with:

- `/events settings timezone`
- `/events settings time-format`
- `/events channel set`
- `/events schedule create`
- `/events schedule list`

Server managers remain responsible for confirming event times and updating schedules when in-game rules or State-specific timings change.
