# Server Setup

Police Chief WikiBot does not require Administrator permission.

## Recommended setup

1. Install WikiBot using its official Discord or Top.gg installation flow.
2. Give the bot access only to the channels where it should operate.
3. Run `/help` to confirm commands are available.
4. Optionally configure an update channel with `/updates`.
5. Optionally configure an event channel, time zone, time format, and recurring schedules with `/events`.
6. Optionally configure the server language with `/settings server-language`.

Server-wide changes require the relevant Discord management permission. WikiBot does not automatically modify roles, channels, or unrelated server settings.

A dedicated WikiBot channel is recommended so interactive results remain easy to find.
