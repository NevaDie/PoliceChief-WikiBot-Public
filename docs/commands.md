# Command Overview

Run `/help` in Discord for the current command overview. Discord remains authoritative when this page and the registered command list differ.

| Command | Purpose |
|---|---|
| `/building` | Building levels, costs, power, time, and requirements |
| `/hero` | Hero information, skills, progression, and equipment |
| `/hero-guide` | Hero recommendations, formations, and development guidance |
| `/item` | Items, currencies, sources, prices, and related systems |
| `/equipment` | Hero Gear attributes and enhancement progression |
| `/research` | Research technologies, costs, effects, and requirements |
| `/k9` | K9 partners, skills, progression, materials, and rewards |
| `/event` | Event tasks, rewards, mechanics, schedules, and sources |
| `/events` | Server event channels, settings, and recurring schedules |
| `/settings` | Personal and server WikiBot settings |
| `/updates` | Server update-announcement configuration |
| `/status` | Content coverage, work in progress, and known gaps |
| `/privacy` | In-bot privacy explanation |
| `/data` | Personal data controls |
| `/feedback` | Private feedback and reports |
| `/credits` | Contributors, sources, and attribution |
| `/vote` | Optional Top.gg voting link |
| `/support` | Optional Ko-fi support link |
| `/help` | Complete in-bot command overview |

Administrative owner-only commands are intentionally not documented as public user commands.
