# Data Quality

Not every Police Chief value can be verified at the same time. WikiBot therefore
labels uncertain or incomplete information instead of presenting every entry as
equally reliable.

- **Confirmed:** directly verified in the live game or an authoritative announcement
- **Reported:** provided by a community member but not independently reproduced
- **Estimated:** calculated or inferred from incomplete observations
- **Preview:** unreleased or pre-release information, separated from live content
- **Incomplete:** known gaps remain

If WikiBot disagrees with the live game, the current in-game information wins.

Public community sources are credited where they are used. Restricted, leaked,
or members-only third-party material is not republished as WikiBot content. AI
tools may help compare or organize observations, but they are not treated as a
source for game facts.
