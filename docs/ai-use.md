# Use of AI Tools

Police Chief WikiBot is maintained by a person. AI tools are used as assistants,
not as the project owner and not as an autonomous operator of the bot.

They may help with:

- drafting or improving code and documentation;
- organizing game observations and checking data for inconsistencies;
- preparing translation drafts for later review;
- troubleshooting and test preparation.

The live Discord bot does not use a generative AI service to answer commands.
Normal command interactions are not automatically sent to an AI provider.

Game facts, translations, and release decisions remain subject to human review.
Machine-generated wording or translations may contain mistakes, so verified
in-game evidence and community corrections take priority.

Private feedback is not routinely used as AI input. If AI assistance is useful
for investigating a report, the project owner should use only the necessary
excerpt and first remove Discord IDs, usernames, server or channel names, and
unrelated personal details.
