# Contributing

Thank you for helping improve Police Chief WikiBot.

## Useful contributions

- Correct verified game data
- Report missing or outdated information
- Confirm official in-game terminology
- Improve German or French translations
- Improve documentation and examples
- Report unclear commands or setup instructions

## Evidence

Whenever possible, include the exact in-game name, language, game version, a screenshot or video, State or progression context, and the date observed.

Do not submit private conversations, personal data, credentials, leaked material, or members-only third-party content.

## How to contribute

- Use `/feedback` for private reports.
- Open a GitHub issue for public documentation, translation, or data corrections.
- Submit a pull request for documentation-only changes.

Submissions may be edited for clarity, consistency, attribution, and data quality before inclusion.
