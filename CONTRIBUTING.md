# Contributing

Police Chief changes regularly, and one person cannot verify every language,
State, or event alone. Well-documented community reports are therefore genuinely
useful.

## Useful contributions

- Correct verified game data
- Report missing or outdated information
- Confirm official in-game terminology
- Improve German or French translations
- Improve documentation and examples
- Report unclear commands or setup instructions

## What makes a report useful

Whenever possible, include the exact in-game name, language, a screenshot or
video, State or progression context, and the date you observed it. It is fine to
say when something is uncertain.

Do not submit private conversations, personal data, credentials, leaked material, or members-only third-party content.

## How to contribute

- Use `/feedback` for private reports.
- Open a GitHub issue for public documentation, translation, or data corrections.
- Submit a pull request for documentation-only changes.

Public visitors cannot directly change this repository. Proposed edits are
reviewed before they are merged, and a submission may be declined even when it
was made in good faith. Please do not ask for repository write access simply to
submit a correction.

Submissions are reviewed before publication and may be edited for clarity or to
match the project's terminology. AI tools may help organize or compare submitted
information, but personal details should not be included and evidence remains
more important than generated text.

By participating, you agree to follow the [Community Guidelines](./CODE_OF_CONDUCT.md).
