# Public Roadmap

This is a working list rather than a release promise. Priorities can change when
the game changes or the community finds a more urgent gap.

## In progress

- Complete the public Privacy Policy and Terms of Service
- Publish the GitHub Pages website
- Keep the command reference aligned with Discord
- Expand verified German and French terminology
- Document translation status and fallback behavior

## Planned

- Public event-data coverage overview
- Translation contribution workflow
- Publicly shareable example data and schemas
- Screenshots and visual setup guides
- Clearer documentation for recurring event schedules

## Long term

- More community-reviewed translations
- Additional public data-quality reports
- Better onboarding for contributors and data corrections
