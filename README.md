# Police Chief WikiBot — Public Resources

This repository is the public home for **Police Chief WikiBot** documentation,
project policies, translation work, and community contributions.

Police Chief WikiBot is a free, independent community knowledge and planning bot for Police Chief players. It is not affiliated with, endorsed by, or officially connected to Police Chief, WAL Games, or their respective owners.

## Want to help?

You do not need coding experience. Confirming an in-game value, reviewing a
translation, reporting outdated information, or supplying a clear screenshot can
all improve WikiBot. Start with the [contribution guide](./CONTRIBUTING.md).

Changes from the public are suggestions only. They are reviewed by the project
owner before anything becomes part of the repository or bot.

The bot's source code and operational data are kept private. This repository does
not contain user data, server configuration, private feedback, credentials, logs,
backups, or internal planning notes.
